Ayuda - Módulo de Consultas

Este módulo permite realizar consultas sobre la base de datos de manera rápida y sencilla. A continuación se explican sus principales funciones:

Funciones principales

  • Selección de tabla: El usuario puede elegir la tabla sobre la que quiere consultar datos.
  • Consulta rápida: Con el botón de búsqueda se genera una vista preliminar de la tabla.
  • Ordenar resultados: Se puede definir si los datos se muestran en orden ascendente o descendente.
  • Consola SQL: Espacio donde se escriben consultas personalizadas.
  • Ejecutar consulta: Ejecuta la instrucción SQL escrita y muestra los resultados.
  • Consultas guardadas: El sistema permite reutilizar consultas previamente almacenadas.

Recomendaciones

  • Verifique que la consulta esté bien escrita antes de ejecutarla.
  • Si se intenta acceder a una tabla inexistente, el sistema mostrará una alerta.
  • Utilice el módulo para facilitar la obtención de información sin necesidad de conocimientos avanzados de SQL.
